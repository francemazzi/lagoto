# Lagoto

**Gli agenti cambiano. Il lavoro resta.**

Lagoto è un progetto open source per un’app desktop local-first che riunisce gli agenti di coding in un’unica interfaccia. Nasce per lavorare con Claude Code, Codex e Cursor senza saltare tra finestre o ricostruire il contesto quando si cambia agente.

## La visione

**Un progetto, uno o più repository.** Una sidebar essenziale, nessun livello workspace. Colleghi backend, frontend e app desktop e gestisci il lavoro da un unico posto.

**Il task appartiene al progetto, non alla chat.** Piano, decisioni, modifiche e risultati dei test devono restare disponibili anche quando una sessione si interrompe. Se Claude raggiunge un limite, l’obiettivo è continuare con Codex dal contesto salvato, mostrando cosa è stato completato e cosa resta da verificare.

**Lo stato è chiaro, senza rumore.** Agente attivo, quote e reset quando disponibili, contesto utilizzato, ultimo checkpoint e criteri verificati. Niente percentuali inventate o dashboard affollate.

Lagoto non vuole essere un altro IDE né un nuovo agente: vuole conservare lo stato verificabile del lavoro e rendere semplice affidarlo all’agente successivo.

## Stato

In fase di progettazione, inizialmente per uso personale su macOS. Le funzionalità descritte sono obiettivi di sviluppo.
